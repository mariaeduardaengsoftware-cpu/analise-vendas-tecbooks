# 📊 Análise de Vendas — TechBooks

## 🎯 Objetivo do projeto

Este projeto tem como objetivo analisar dados fictícios de vendas da TechBooks, uma empresa de exemplo que comercializa produtos das categorias Eletrônicos, Roupas e Livros.

Utilizando Python, Pandas e SQLite, foram realizadas análises para compreender o faturamento, identificar produtos com maior valor de venda e comparar o desempenho das categorias ao longo do ano de 2026.

## 🛠️ Tecnologias utilizadas

- **Python:** linguagem utilizada para desenvolver a análise.
- **Pandas:** manipulação, organização e análise dos dados.
- **SQLite:** armazenamento e consulta dos dados de vendas.
- **Matplotlib:** criação de gráficos.
- **Seaborn:** personalização das visualizações.

## 🔎 Análises realizadas

- Filtragem de vendas com valores superiores a R$ 1.000,00.
- Ranking de faturamento por produto.
- Análise do faturamento mensal.
- Comparação do faturamento entre categorias.

## 📈 Principais resultados

- **Faturamento total:** R$ 8.450,00.
- **Quantidade de vendas registradas:** 14.
- **Categoria com maior faturamento:** Eletrônicos, com R$ 5.900,00.
- **Maior venda individual:** Smartphone, no valor de R$ 2.500,00.

## 💡 Conclusão

O projeto permitiu praticar conceitos de consulta a bancos de dados, manipulação de dados com Pandas e criação de visualizações com Matplotlib e Seaborn.

A análise demonstra como os dados podem ser organizados e transformados em informações úteis para compreender o desempenho de um negócio e apoiar a tomada de decisões.
